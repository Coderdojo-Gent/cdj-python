Tips voor coaches:

- **Raad het Getal**: de PDF vergelijkt getallen met `is`. Leer de kinderen `==` gebruiken. `randrange(1, 10)` kiest 1 tot en met 9.
- **Schildpad**: de PDF gebruikt IDLE. In VS Code moet `turtle.done()` onderaan, anders gaat het venster meteen dicht.
- **Waar is het ISS?**: `turtle` zit al in Python, `pip install PythonTurtle` is niet nodig.
- **Snake**: de installatie-uitleg in de PDF is verouderd, gebruik gewoon `pip install pygame`. Groen en blauw zijn omgewisseld: blauw is `(0, 0, 255)`.
